# 把想法写下来，让笔记连起来

这是你的 **Aero 示例库**。这些笔记都是普通 Markdown，可以改、可以移动、可以改名。你改过的内容保存在本机；下次打开或更新应用时，Aero 只替换你没动过的示例。

> [!tip] 从这里开始
> 点进这段文字即可编辑。字的位置和粗细不会变，只多出光标。按一次 `Esc` 选中整块，再按一次回到浏览。

## 一分钟小练习

- [ ] 打开 [[Markdown 排版]]，改一句话，再按两次 `Esc`。
- [ ] 把鼠标停在 [[项目清单]] 上，看只读预览。
- [ ] 按 `⌘P` 搜索“连接笔记”，体验 [[连接笔记|按别名查找]]。
- [ ] 选中几个字，用选区上方的工具条改成粗体或颜色。`⌘⇧H` 会重复上次的颜色，第一次是黄色高亮。
- [ ] 点标题行右侧的反链计数，看哪些笔记连到这一页。

==正文只是文件，连接让它成为知识库。==

## 打开你自己的笔记

按 `⌘O` 选择已有文件夹；也可以通过「文件 → 关闭 Vault」回到库选择页，再从最近列表切换，或者再点一次「查看示例库」回到这里。

Aero 启动时停在库选择页，不会自动打开任何笔记库；运行 `aero /你的/笔记目录` 可以直接打开指定库。示例库位于应用数据目录的 `demo-vault/`，不在安装包内；卸载应用通常不会删除这里的文件。

新版本可能带来更新过的示例。再次进入示例库时，Aero 只会替换你没有改动过的那几篇，并补上新增的示例；你改过、删掉或改名的文件保持原样。
