# 让内容有清晰的层次

一段文字可以包含 **重点**、*语气*、`行内代码`、~~不再采用的想法~~，以及 ==值得回看的句子==。

选中文字后试试 `⌘B`、`⌘I`、`⌘E`、`⌘⇧S` 或 `⌘⇧H`；再次执行可以取消相应格式。

## 清单与表格

- 记录一个观察。
- 给它补充上下文。
- 用 [[双链与别名]] 连接相关材料。

1. 先写下草稿。
2. 再调整结构。
3. 最后回顾结论。

| 状态 | 今天要做的事 | 关联笔记 |
| :--- | :--- | :---: |
| 进行中 | 做一个小型写作计划 | [[项目清单]] |
| 待整理 | 给重要段落加链接 | [[标题与块引用]] |

## 引用与提示

> 好笔记不必一次写完；能让未来的自己继续思考就很好。

> [!note] 留下上下文
> 写清楚“为什么”，比只记一个结论更容易复用。

> [!tip]- 点击展开一个小提示
> 这是一段可折叠的 callout。折叠状态不会写入 Markdown 正文。
