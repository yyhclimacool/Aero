# 写下去，标记会藏起来

点进一段字就能改。字的位置不变，只多出光标。按一次 `Esc` 选中整块，再按一次回到浏览。浏览时点链接会打开它；正在编辑的那一段里，点链接只是放光标。

下面每条都先用行内代码写出你要打的字，再给出 Aero 实际画出的样子。想看整篇源码，用 `⌘⇧P` 打开命令面板，选「查看源码」。`⌘,` 里可以打开「聚焦时显示源码」。

## 网页链接

方括号里是显示的字，圆括号里是地址。

写成 `` `[url](www.google.com)` `` 时，页面上是一个链接：[url](www.google.com)。单击会用浏览器打开。地址没有 `http://` 或 `https://` 时，Aero 会补上 `http://`，所以 `rustup.rs`、`myapp.zip` 这种奇怪的地址也同样打开网页，而不会被当成库里的文件。

带协议的写法：[Google](https://www.google.com)。

尖括号里的地址会直接显示网址：`<https://www.google.com>` → <https://www.google.com>。单独写 `www.google.com` 也会变成链接，并按 `http://` 打开。

`⌘K`：有选区时把选中的字变成链接；没有选区时插入 `[[` 并打开笔记候选。

## 连到另一篇笔记

| 写法 | 效果 |
| --- | --- |
| `[[项目清单]]` | 按标题或文件名链接 |
| `[[项目清单\|显示的字]]` | 竖线后面是显示文字 |
| `[[写作计划]]` | 用对方 front matter 里的 alias |
| `[[标题与块引用#章节链接]]` | 跳到某一节 |
| `[[标题与块引用#^seedidea]]` | 跳到带 `^id` 的那一块 |

输入 `[[` 会补上 `]]` 并列出笔记。`![[` 用来嵌入：笔记嵌入要独占一段才画出来，见 [[双链与别名]]。章节和块的跳转见 [[标题与块引用]]。还没有的笔记是淡色虚线，点击才创建；[[双链与别名]] 里留了一个例子。重名时会提示消歧，不会直接建文件。

## 字的样式

| 按键 | 写法 | 看到的 |
| --- | --- | --- |
| `⌘B` | `**重点**` | **重点** |
| `⌘I` | `*语气*` | *语气* |
| `⌘E` | `` `代码` `` | `代码` |
| `⌘⇧S` | `~~划掉~~` | ~~划掉~~ |
| `⌘⇧H` | `==高亮==` | ==高亮== |

再按一次同一快捷键会取消。`⌘⇧H` 重复上次用过的颜色，还没用过时是黄色高亮。

选中文字后，工具条上的 `A` 可以上色。调色板是灰、棕、橙、黄、绿、蓝、紫、粉、红，文字色和背景色可以叠在一起：[红字]{.red}、[蓝底]{.bg-blue}、[红字黄底]{.red .bg-yellow}。黄色背景写成 `==高亮==`。整段上色写在段末：` {.bg-blue}`。空行开头输入 `/红色` 或 `/蓝色背景` 也行。更完整的例子在 [[Markdown 排版]]。

## 块

空行开头输入 `/`，可以换成这些块（也可以用后面的快捷键）：

| 菜单 | 快捷键 | 写法 |
| --- | --- | --- |
| 文本 | `⌘⌥0` | 普通段落 |
| 标题 1 / 2 / 3 | `⌘⌥1` `⌘⌥2` `⌘⌥3` | `#` `##` `###` |
| 无序列表 | `⌘⌥4` | `- 一项` |
| 有序列表 | `⌘⌥5` | `1. 一项` |
| 任务 | `⌘⌥6` | `- [ ] 待办` |
| 引用 | `⌘⌥7` | `> 引用` |
| 代码块 | `⌘⌥8` | 三反引号围栏 |
| 分割线 |  | `---` |
| 今天日期 |  | 插入当天的 `YYYY-MM-DD` |

公式、表格、提示框和图不在 `/` 菜单里，直接写：

- 行内公式 `$E = mc^2$` → $E = mc^2$
- 块级公式用单独的 `$$` 围起来
- 表格用 `|` 分列
- 提示框：`> [!note]`、`> [!tip]`、`> [!warning]`、`> [!info]`，标题后加 `-` 表示默认折叠
- 代码块语言写成 `mermaid` 时画成图

任务方框直接点，不用先进入编辑。列表里按 `⏎` 会续一项，再按一次空项就退出。`⇧⏎` 是段内换行，不拆成新块。

悬停左侧 `⠿` 可以拖动重排；点击或按 `⌘/` 打开块菜单：转换、颜色、编辑源码、复制块链接、添加 `^id`、复制块、删除。

## 图片和附件

粘贴图片，或从访达拖进编辑区，文件会进当前笔记的 `.assets/`。图片和 PDF 插入 `![[文件名]]`，整段只有图片时才显示图。拖图片边缘改宽度，双击看大图，`Esc` 或空格关闭。

PDF 写成 `![[文件.pdf]]`。有文件时可以翻页：`←` `→` 换页，`⌘⏎` 用系统阅读器打开。

其他文件插入库内指针，例如 `` `[[notes.zip]](笔记名.assets/notes.zip)` ``。页面上是文件图标和名字，单击在访达里定位。对不上现有文件时不会新建。从文件树把笔记拖进正文会插入 `[[笔记]]`，按住 `⌥` 则是 `![[笔记]]`。

## 找笔记、管窗口

| 按键 | 作用 |
| --- | --- |
| `⌘P` | 快速打开笔记（标题、别名、路径） |
| `⌘⇧F` | 全文搜索。正文标签和文首 tags 一样能被找到，例如 #示例/入门 |
| `⌘⇧P` | 命令面板 |
| `⌘N` | 新建笔记 |
| `⌘⇧D` | 打开或创建今天的日记 `daily/日期.md` |
| `⌘O` | 打开另一个文件夹作为库 |
| `⌘S` | 立即保存（平时也会自动保存） |
| `⌘T` / `⌘W` | 新建 / 关闭标签页 |
| `⌘⇧T` | 重新打开刚关掉的标签页 |
| `⌘1`–`⌘9` | 切到第几页，`⌘9` 是最后一页 |
| `⌘\` | 折叠左侧栏 |
| `⌘⇧\` | 折叠右侧面板 |
| `⌘⇧E` | 在文件树里定位当前笔记 |
| `⌘Z` / `⌘⇧Z` | 撤销 / 重做 |

文件树里选中一篇，按 `F2` 改文件名，链接会跟着改。点编辑区顶部的标题，改的是 front matter 里的 `title`。练习见 [[移动与改名]]。
