# 不只链接整篇笔记

当笔记变长时，可以让链接直接指向章节，或指向一个有明确 ID 的块。

## 章节链接 {.blue}

[[#章节链接|这个链接跳到当前章节]]，[[项目清单#下一步|这个链接跳到项目的下一步]]。

输入 `[[笔记名#` 可以选择该笔记中的标题；只输入 `[[#` 则列出当前文档标题。标题末尾的颜色不会进链接文字，所以上面的蓝色标题仍然叫“章节链接”。

### 章节里的补充说明

悬停章节链接时，预览包含这个小节，但不会延伸到下面的同级章节。

## 块引用

一条想法值得保留，是因为它能回答一个具体问题，而不只是因为它听起来很好。 {.bg-yellow} ^seedidea

上面的段落带有显式块 ID `seedidea`，可以通过 [[#^seedidea|这条精确引用]] 直接定位。颜色写在 `^id` 前面，两者可以同时存在。

输入 `[[笔记名#^` 可以按块摘要选择目标；没有 ID 的块会在确认时自动补上 ID。选中文字后，工具条右侧的 `⋯` 也可以复制指向这块的链接。

## 看“此块的引用”

点击上面的想法段落进入编辑，再按一次 `Esc` 选中该块。右侧反链面板会出现“此块的引用”，其中包括 [[双链与别名]] 和 [[项目清单]] 中的引用。
