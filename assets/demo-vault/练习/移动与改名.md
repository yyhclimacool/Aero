# 换个位置，连接仍然在

这篇笔记可以作为安全的整理练习。先打开 [[项目清单]]，看看其中指向本篇的链接，然后再回来。

## 练习一：移动文件

把文件树中的本篇拖到“项目”文件夹，或者拖到“Vault 根目录”。Aero 会同步更新指向它的链接，并调整本篇的相对链接。

下面保留了一个普通 Markdown 链接和一个引用式链接，方便切换源码观察路径变化：

- [普通 Markdown 路径](../项目/项目清单.md#下一步)
- [引用式路径][plan]

[plan]: <../项目/项目清单.md> "写作项目"

普通 Markdown 链接在这里用于演示源码路径同步；笔记间跳转请使用 [[项目清单]]。

## 练习二：改文件名与改标题

- 文件树选中本篇，按 `F2` 或右键选择“重命名”：修改的是文件名。
- 点击编辑区顶部的标题：本篇有 front matter `title`，因此修改的是标题，同时更新受影响的标题引用。
- 直接在 YAML 源码中修改 `title` 只更新解析和索引，不自动改写其他笔记。

> [!tip] 放心试，但记得这是你的文件
> 改过的示例不会被应用更新覆盖，重新启动或重新安装也不会把本篇恢复成原样。移动和改名目前没有全库撤销；可以再移动或改回去。
