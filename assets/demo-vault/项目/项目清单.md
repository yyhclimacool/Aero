# 写一篇让自己满意的短文

**目标**：用三段话解释一个最近学会的概念。排版可以参考 [[Markdown 排版]] 里的 [颜色与公式]{.purple}。

> 参考 [[标题与块引用#^seedidea|一条关于笔记价值的想法]]，写下你真正想回答的问题。
