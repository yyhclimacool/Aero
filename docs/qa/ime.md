# M1 macOS 输入法验收

## 本次自动验收（2026-09-16）

在 Aero 实际 Editor + gpui-base Textarea 上调用平台 IME 协议，无头绘制并验证 Document/磁盘；不是只测独立控件。

| 用例 | 结果 | 自动测试 |
| --- | --- | --- |
| 中文 `nihao → 你好`；在 `前😀 **ab** 后` 的粗体内部组合 | 通过 | `ime_preedit_commit_and_undo_preserve_markdown` |
| 日文 `にほんご → 日本語`，包含多字节前缀和 Markdown 边界 | 通过 | 同上 |
| 预编辑持续超过 500 ms 时，不进入 Document、不自动保存临时拼音 | 通过 | 同上 |
| 提交后一次文档级撤销恢复原文，不残留拼音/假名 | 通过 | 同上 |
| 在 `[[目标]]` 内取消组合，不改原文、不产生撤销记录 | 通过 | `ime_cancel_does_not_change_document_or_disk` |

复跑：`cargo test --locked -p aero-app ime_`。

## 原生输入法完整人工验收（尚未完成，不能计为全部通过）

M0 的独立控件记录在 `docs/decisions/0001-ui-toolkit.md`，不能替代本表。下列项目需要原生 macOS 候选窗和真实输入源；自动调用 IME 协议不覆盖候选窗、输入法快捷键或系统切换行为。

测试环境记录：构建 commit/本地 diff、macOS 版本、屏幕缩放、输入法名称和版本、测试人、日期。
在独立临时 vault 新建以下内容，避免用真实笔记做破坏性测试：

```markdown
# 中文标题

前😀 **加粗文字**，[[目标]]，#tag

- 列表中的中文

> 引用中的日本語

长段落：重复文本，直到在编辑区出现至少三行软换行。
```

分别用系统简体拼音、常用第三方中文输入法、日文输入法执行并记录“通过/失败 + 复现步骤”：

- [ ] 预编辑有下划线，候选框位于当前光标旁；段首、段中、末尾都检查。
- [ ] 光标跨软换行、滚动到屏幕底部、缩放窗口后，候选框仍跟随光标且不被裁切。
- [ ] 组合期间按 Esc、方向键、Backspace，由输入法处理，不能误触块选择、跨块移动或删除整个块。
- [ ] 在 `**`、`[[`、`#` 和列表标记附近输入；提交不会吞字、重复插入或拆错块。
- [ ] 切换中文/英文/日文输入源，预编辑正确提交或取消，无残留文本。
- [ ] 一次提交后 ⌘Z/⌘⇧Z 正确撤销/恢复；随后输入新内容，撤销粒度符合预期。
- [ ] 组合期间切换笔记、失焦、关闭窗口，已提交文字正确落盘，预编辑不污染文件。

只有这张表在实际应用中完成，M1 的原生 IME 验收才能关闭。
