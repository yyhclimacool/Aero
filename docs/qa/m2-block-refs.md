# M2 块引用验收

日期：2026-09-18。

## 功能范围

- 输入 `[[笔记#^` 列出目标笔记的块，`[[#^` 使用当前未保存文档。笔记名支持已有的路径 / 文件名 / front matter `title` 解析与消歧。
- 每条显示正文摘要前 60 个 Unicode 字符、块类型、已有 ID（或确认后生成 ID）及路径；按摘要或已有 ID 模糊匹配，空查询按文档顺序，最多显示 8 条。
- `↑↓` 选择，`⏎` / `Tab` / 鼠标插入，`⇧⏎` 生成并选中别名，`Esc` 关闭。复用现有闭括号，保留后续文字；表格别名使用 `\|`。代码、数学、转义、URL 和嵌入语法内不触发。
- 读取候选不修改文件。确认时复用唯一的已有 ID，否则生成当前文档内不重复的 6 位 base32 ID。段落追加行尾标记，多行块使用独立标记行；已有属性标记保留，引用 / 列表内保持续行上下文。
- 写入前重新解析，并比较块层级、类型、属性、已有 ID 与新增 ID 的归属，避免拆分容器或把标记吞进未闭合代码块。不具备安全写入位置时显示错误、保留输入。
- 外部文件按菜单加载时的内容指纹检查，准备后再次检查，再原子写入单个标记；保留原 BOM、混合行尾及其余字节。目标变化、删除、读取 / 写入失败或重复 ID 时不插入引用。
- 同篇使用内存里的未保存内容，补 ID 与插链接作为一个撤销组，重做复用同一个 ID。跨篇先持久化目标 ID，撤销来源链接时保留目标 ID，符合设计 6.3.3；不声称跨文件原子事务或跨进程文件锁。
- 点击 `[[笔记#^id]]` / `[[#^id]]` 按显式 ID 定位，缺失或重复时提示且不猜测。引用内的块定位其可见容器并展开折叠 callout；整段列表定位其首个可见编辑单位。块引用的目标笔记不存在时不创建空笔记。
- 外部目标写入后发出路径变更事件，更新文件树、搜索索引与反链。切换笔记 / 标题 / 块补全模式后，旧目录回复不能覆盖新菜单；输入法预编辑不确认候选。

## 自动化

新增 13 项测试：核心 5 项、补全纯函数 1 项、无头 GPUI 编辑器 6 项、工作区集成 1 项。

- 段落属性、嵌套列表 / 引用、标题、整段列表、围栏及缩进代码、表格、callout、数学块与独立属性行的 ID 写入和解析归属。
- 复用已有 ID、重复 ID 拒绝、未闭合围栏拒绝、Unicode 摘要长度、元数据排除。
- BOM / 混合换行字节保持、外部修改 / 删除保护、重复引用不再次写入。
- 同篇未保存内容、一次撤销重做、鼠标确认与光标、片段转义、表格别名、IME、空结果、模式切换与过期回复。
- 块 ID 点击定位、缺失 / 重复时保留高亮、折叠 callout 自动展开。
- 工作区加载未索引笔记 → 确认补 ID → 插入引用 → 点击打开目标 → 来源落盘 → 搜索与反链更新。

## 范围限制与后续

- 候选排除 front matter、纯标记、原样透传的 Raw 块和列表项包装节点；列表内可选择正文块或整段列表。同篇排除正在输入链接的块及其包含容器，避免半成品查询成为自己的候选。
- 现有链接含显示别名时不在内部打开补全；新链接可用 `⇧⏎` 生成别名。外部文件变化后需重新打开菜单获取新候选。
- 外部目标确认时同步提交一个文件；大文件 / 慢磁盘的确认延迟尚未基准验收。ID 清理、块级反链筛选与嵌入渲染仍待实现。
- 下一项为 `![[` 嵌入 / 附件补全；front matter `aliases` 搜索、`⌘K`、自动配对也尚未完成。

本轮使用无头 GPUI 交互测试；原生视觉、真实系统输入法和个人真实语料尚未人工验收。应用包未重新打包或替换。
