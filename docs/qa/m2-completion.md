# M2 笔记链接补全验收

日期：2026-09-17。

## 本轮范围

- 输入 `[[` 打开光标旁的笔记候选，标题 / 路径模糊匹配，最近打开优先，最多显示 8 条；每条同时显示标题与完整路径。
- `↑↓` 循环选择，`⏎` / `Tab` / 鼠标插入，`⇧⏎` 插入 `[[目标|显示别名]]` 并选中别名，`Esc` 只关闭菜单、保留输入。未开菜单时 `⇧⏎` 仍是软换行。
- 无匹配时插入未解析链接，不创建文件；后续点击沿用已有的创建笔记流程。目录加载中 / 读取失败不会被误当成无匹配。
- 段落、标题、列表、引用、callout、表格源码中可用；代码、数学、转义文本、链接 URL 和笔记嵌入内不触发。表格别名使用 `\|`，保留列结构。
- 有现成 `]]` 时复用闭括号。编辑现有链接的笔记名时若带别名 / 标题片段，保留其源码；标题片段内的补全后续已实现，见 [标题补全验收](m2-headings.md)。鼠标确认后光标留在插入末尾，可继续输入；完整插入可一次撤销 / 重做。
- 同名笔记优先写可验证的限定路径；根路径被相对路径遮蔽时尝试唯一标题，无法表示时保留输入并提示，不静默指向另一篇。文件名中的 `#` 正确转义。
- 候选目录在后台读取：索引提供已有标题，未索引文件从磁盘补标题；遵守 vault 忽略规则。每次新开菜单读取一次快照，输入时过滤；关闭或重新开启后丢弃旧请求。选区 / 光标离开、切块、撤销、重载、改名和打开快速面板会收起菜单。确认时检查目标是否仍存在。
- 输入法预编辑不写入文档，也不确认旧候选；提交文字后再过滤。

- 真实键盘 / 鼠标事件、别名替换、单步撤销重做、闭括号复用、继续输入、引用及表格结构保持。
