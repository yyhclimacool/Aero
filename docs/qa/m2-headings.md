# M2 标题链接补全验收

日期：2026-09-17。

## 功能范围

- 输入 `[[笔记#` 列出目标笔记标题，`[[#` 列出当前笔记的未保存标题。笔记支持文件名、路径与 front matter `title` 解析；输入标题后插入经消歧验证的链接目标。
- 按标题文本模糊匹配，支持中文、大小写不敏感；空查询按文档顺序列出，最多 8 条，显示标题级别与所在路径。同文本标题只列首处，链接定位第一处。
- `↑↓` 选择、`⏎` / `Tab` / 鼠标插入、`⇧⏎` 插入并选中显示别名、`Esc` 关闭。已有 `]]` 会一起替换，确认后光标留在链接末尾；一次插入可单步撤销 / 重做。表格别名使用 `\|`，保留列结构。
- 补全、大纲和点击定位共用 Markdown AST 提取的标题显示文本：识别 ATX、Setext、多行标题、行内强调 / 代码 / 链接、HTML 实体、属性和引用容器；链接目标与片段中的 `#` 正确转义。
- 引用或 callout 内的标题跳转至包含它的编辑单位；折叠 callout 自动展开并高亮容器。顶层标题直接定位其标题块。
- 其他笔记在后台读取；本篇短链接无需等待索引，本篇具名链接也使用内存内容。笔记补全切换到标题补全、目标变化或菜单关闭后，旧请求不能覆盖新结果。
- 加载中、读取失败、未找到笔记、笔记名有歧义、没有匹配标题时保留输入并显示相应提示。确认前检查外部目标文件是否仍存在；不创建文件。无法用现有链接语法表示的标题（如含 `|`）提示修改，不写入错误目标。
- 复用已有的 Markdown 上下文、光标 / 选区与 IME 防护；代码、数学、转义、URL、嵌入中不打开菜单。输入法预编辑不写文档、不确认旧候选。
