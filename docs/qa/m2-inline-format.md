# M2 行内格式验收

日期：2026-09-20。

## 功能范围

| 入口 | 格式 |
| --- | --- |
| `⌘B` | `**粗体**` |
| `⌘I` | `*斜体*` |
| `⌘E` | 行内代码 |
| `⌘⇧S` | `~~删除线~~` |
| `⌘⇧H` | `==黄色高亮==` |

- 编辑菜单和命令面板提供相同操作。作用于聚焦的正文编辑区；命令面板返回后恢复原选区。
- 有选区时包裹非空白正文，并继续选中正文；选中完整已包裹元素或其完整正文时再次执行，取消该格式且保留内部格式。选区两端的空白保持在标记外。
- 无选区时插入空标记，光标放中间；再次执行同一动作可移除空标记。格式操作为独立撤销组，后续输入与格式操作分开撤销 / 重做。
- 支持中文 / emoji、嵌套行内格式、完整行内代码、Markdown 链接文字、列表、标题正文、引用 / callout、表格中的转义竖线。核心层复用行内链接的源码位置映射，校验生成的 AST 格式节点、块类型 / 层级 / 属性 / ID。
- 行内代码采用比内容中最长反引号序列多一枚的分隔符，并在需要时加边界空格。取消时保留代码原始内容。
- 黄色高亮在预览和源码编辑态绘制原生背景，适配浅色 / 深色主题；源码态背景跟随自动换行，取消、删除标记和撤销 / 重做后刷新。预览保留嵌套格式、链接、表格与 callout 折叠。
- 输入法预编辑期间不执行；代码 / 数学内部、链接 URL、front matter、图片 / wikilink、结构标记、跨行 / 跨块或不能保持块结构的选区不改写。带属性的代码不移除或重新包裹承载属性的代码节点。

## 范围限制与后续

- `⌘⇧H` 已改成「应用上次使用的颜色」（默认仍是黄色高亮）；其他文字 / 背景色走颜色菜单。选区浮动工具条见 [选区浮动工具条验收](m2-toolbar.md)。
- 局部选中已有格式的一部分时，不拆分原有格式节点；无法生成预期格式时保持原文。跨行 / 跨块格式编辑留待后续。
- 已验证无头 GPUI 的布局和实际背景绘制指令，但原生窗口视觉、真实系统输入法和个人真实语料仍需人工验收；应用包未重新打包或替换。
