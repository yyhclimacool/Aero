## 原有功能范围（2026-09-18）

- 在正文编辑态选中文字按 `⌘K`，生成 `[文字](url)` 并选中 `url` 待输入。剪贴板为单个 HTTP / HTTPS / FTP / mailto / file URL 时自动填入并选中地址；普通文字、多行内容或无法解析的地址使用占位。URL 解析器复用依赖树中的 `url 2.5.8`。
- 剪贴板 URL 按 URL 规则规范化，并对 Markdown 中的括号、竖线、引号等作百分号编码，对 `&` 作实体转义；保持 URL 语义和表格列结构。生成内容仍是普通 Markdown 源码，没有新的存储格式。
- 光标或选区位于已有显式行内链接 `[label](destination "title")` 中时，只选中地址，不改文字、行内格式、标题、空白或括号；支持尖括号地址、空地址、转义及嵌套圆括号。选中地址本身不修改文档、不增加撤销记录；随后输入由现有文本编辑 / 保存流程处理。
- 无选区且不在已有链接内时插入 `[[]]`，光标置于中间并打开笔记补全。已有半成品 wikilink 则重新打开菜单，不增加括号；已有 wikilink 可继续补全，或选中目标进行源码修改。带标题 / 别名的源码保护沿用已有补全规则。
- 同一动作可从「编辑 → 插入或编辑链接」和命令面板调用。命令面板保留并恢复正文选区；搜索框、笔记标题框、浏览态和块选中态不插入行内链接。
- 支持中文 / emoji、强调和完整行内代码、标题正文、列表、引用 / callout 和表格单元格。必要时转义标签中的方括号，保留已有转义与代码内容；生成结果重新解析验证，并检查块层级、类型、属性和显式 ID 保持不变。
- 表格中 comrak 行内位置经过 `\|` 解码，选区映射回原始字节，编辑后保留相邻链接和单元格。新链接包裹是独立撤销组，后续地址输入也可撤销；不把包裹与此前输入合并。
- 输入法预编辑期间不执行；普通代码 / 数学内部、图片 / 嵌入、HTML / front matter、结构标记、跨行、跨越已有链接或无法保持结构的选区不改写。

## 2026-09-21 链接预览与视觉区分

- 已解析链接使用强调色实线，缺失笔记使用淡色虚线，歧义使用警示色虚线并列出候选；悬停不创建文件。跨篇缺失标题 / 块片段在悬停读盘后提示，不保证提前显示为淡色。
- 悬停 500 ms 显示只读纯文本浮层。普通笔记取前 300 个 Unicode 字符，去掉 front matter；标题片段截止下一同级 / 更高标题或当前容器末尾，块链接只显示唯一 ID 的目标块。
- 同篇预览使用未保存文档，其他笔记后台读取；外部 URL 只显示完整地址，不请求网络。离开链接后有 150 ms 宽限进入可滚动浮层。
- 编辑、重载、改名、删除、打开快速面板、滚动、窗口缩放或失活取消预览；过期异步结果不能重新打开浮层。
- 仓库内 `forks/gpui-kit/crates/base` 提供链接样式 / 悬停接口，普通 Markdown、高亮 HTML、表格和 callout 共用该接口；不修改全局 Cargo registry。

回归包括 500 ms 定时、移入浮层、旧请求取消、未保存内容、标题 / 块范围、真实鼠标悬停与视觉行几何、裁剪、多行 / 混合格式、链接图片和原有点击行为。运行命令：

## 范围限制与后续

- 地址直接在 Markdown 源码中编辑；没有单独的 URL 编辑弹窗或链接删除按钮。编辑已有地址时不自动用剪贴板覆盖；手动输入遵循普通 Markdown 语法。
- 引用式链接 `[text][id]`、自动链接和图片地址不通过 `⌘K` 编辑；不修改共享引用定义。跨行和跨块选区不包裹。原生菜单视觉、真实系统输入法及大文档延迟尚未人工验收。
- 自动配对与行内格式快捷键已实现，见 [自动配对验收](m2-pairs.md)、[行内格式验收](m2-inline-format.md)。front matter `aliases` 搜索见 [补全记录](m2-completion.md)。富文本悬停预览与「悬停 / 按住 ⌘ / 关闭」见 [链接预览验收](m2-link-preview.md)。
