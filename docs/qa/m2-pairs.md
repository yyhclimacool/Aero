# M2 自动配对验收

日期：2026-09-20。

## 功能范围

- 在正文编辑态逐键输入 `**`、`==`、反引号、`$`、`[[`、`(`、`"`，补齐对应闭合符并把光标留在中间。双字符标记在第二个字符输入后配对，不把连续第三个字符作为新配对。
- 输入当前跟踪的闭合符时只向右移动光标，不重复插入、不增加撤销记录。空配对按退格同时删除两侧；配对插入和整体删除可分别单步撤销 / 重做。
- 内部文字编辑及嵌套配对会更新标记位置；修改标记本身则停止跟踪。笔记与嵌入补全复用自动生成的 `]]`，确认候选后不重复闭合。
- 只观察当前聚焦正文的原生按键，实际文本和光标与单键操作吻合后才修正。粘贴、选区替换、程序化编辑、输入法预编辑及其提交不额外配对。修正使用最小范围替换，文档撤销栈只接收最终结果。
- 在链接扫描认可的正文上下文中生效，覆盖标题、列表、引用 / callout 和表格；代码、数学、链接地址、元数据、转义位置不触发。右侧紧接普通文字时不自动插入闭合符，单词内的双引号不配对。

## 自动化

新增 **13 项测试**：配对状态与上下文 5 项、无头 GPUI 编辑器 7 项、工作区集成 1 项。

- 所有分隔符的输入、跳过与光标位置；空配对删除、嵌套配对、手写闭合符和独立撤销 / 重做。
- 编辑前后区间更新、修改标记失效；代码 / 数学 / URL / 元数据 / 转义防护；粘贴、选区替换和过期按键快照保持原文。
- `[[` / `![[` 菜单复用闭括号，表格和 callout 结构保持，模拟 IME 预编辑 / 提交不配对。
- 工作区实际输入 → 笔记补全 → 保存 Markdown → 撤销补全 → 再保存，包含索引不可用时的磁盘候选。

## 范围限制与后续

- 仅跟踪当前聚焦编辑会话中自动产生的标记；文件已有标记、切换块或撤销 / 重做后恢复的标记按普通文本处理，不再自动跳过或成对删除。
- 不包裹已有选区，不包含其余行内格式快捷键、可配置配对开关或中文全角标点配对。本轮不改变续行规则。
- 使用无头 GPUI 测试；真实系统输入法、原生窗口视觉、大文档输入延迟和个人真实语料尚未人工验收。未重新打包或替换已安装应用。
