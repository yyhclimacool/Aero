# M2 移动、重命名与标题引用同步验收

更新日期：2026-09-22。此前同目录重命名与 aliases 的验收日期分别为 2026-09-17、2026-09-21。

## 功能范围

- 文件树中的笔记和文件夹可拖到另一个目录或「Vault 根目录」，落点高亮；支持空目录。文件树 F2 / 右键「重命名」编辑文件名，Enter 提交，Esc / 失焦取消。重名目标拒绝，不覆盖、合并目录或自动另起名字。
- 文件树改名始终改文件名；编辑器标题有 front matter `title` 时改属性，否则改文件名。**仅标题编辑入口**同步 title 引用；手改 YAML 或外部程序修改仍只刷新解析与索引，不自动修改其他笔记。
- 移动笔记时 `<note>.assets/` 一起移动；移动文件夹保留整个目录，包括空目录和非 Markdown 文件。引用扫描遵守 vault 忽略规则，不读取附件内容、不跟随符号链接。
- 同时更新入链与被移动笔记的相对出链：Wikilink / 笔记嵌入、普通 Markdown 链接、图片、实际生效的引用定义，以及这些链接中的显式附件路径。
- 普通 Markdown 地址按来源目录解析，允许不越出 vault 的 `../`，`/` 表示 vault 根；处理百分号编码。外部 URL、纯片段、自引用片段、未解析 / 歧义目标、代码 / 数学 / HTML 中的伪链接不改写。不会搜索替换任意正文或 YAML 中的路径文字。
- 保留链接显示文字、Markdown title、fragment / query、尺寸参数、空白与未涉及的字节，包括 BOM、混合 CRLF/LF 和末尾换行。仍有效的 title / aliases 目标不改；新标题有歧义或落入图片命名空间时使用可验证的笔记路径。
- 普通 Markdown 地址位置由 AST 和内存重解析共同校验；未使用或重复无效的引用定义不改。无法可靠定位已识别的目标时停止，而不是悄悄漏改。

## 提交与失败恢复

准备只读磁盘，不依赖可重建索引。先保存当前编辑器；正在保存、保存失败或准备期间继续编辑则不提交。需要改写超过 20 个其他文件时确认实际数量，可取消；仅搬位置但正文不变的文件不计入链接改写数量。

提交前重新核对笔记、文件和目录列表、笔记内容指纹及原文，拒绝目录自嵌套、符号链接祖先、隐藏 / 附件目录目标与冲突路径。所有待写笔记原件先备份至 `.aero/rename-<id>/`；Unix 恢复目录权限为 `0700`，manifest 记录原路径、移动目标及备份对应关系。

目录与附件目录使用不覆盖目标的原生迁移；迁移后再次核对忽略规则下的可见笔记和附件列表，若目标规则改变可见性则回滚。普通写入失败逆序撤回已改写文件，再恢复文件 / 文件夹和附件位置；回滚时新出现的外部内容保留并报告，绝不直接覆盖。失败保留恢复目录供人工核对，成功清理恢复目录。

这不是多文件崩溃原子事务；最终校验与发布之间的外部竞争仍存在。提交与编辑器换路径在同一次 UI 回调内完成，防止本应用自动保存插入迁移过程；大库提交延迟尚未验收。目录移动后的索引按有序队列与磁盘整体对齐，普通笔记改名保留原增量路径；搜索、反链、最近笔记和编辑器换路径后刷新，后续保存不复活旧文件。

```sh
cargo fmt -p aero-core -p aero-index -p aero-app -- --check

```

## 未包含与限制

- Finder 导入、跨 vault 移动、外部程序移动 / 改名的引用自动迁移。
- 手动 YAML / 外部 title 变化的自动入链改写。
- HTML 属性、任意正文和 front matter 中的附件路径文本；附件导入、渲染与孤儿检测。
- 全库撤销、自动崩溃恢复、跨文件系统移动。跨文件系统操作失败时不静默退化为覆盖式复制。
- 普通 Markdown 链接此次只增加移动同步，不改变既有跳转与反链索引范围。
- 源区间验证会重复解析文档；超大文件 / 大库性能、原生窗口人工视觉、真实系统 IME 以及非 macOS 原生移动 API 尚未验收。
