# M2 浏览与编辑一致验收

更新日期：2026-09-23。对应 [方案 9.1](../project_plan.md) 与 [UI 设计 5.2](../ui_design.md)。

已交付：文字类块浏览与编辑是同一个文本控件，点进去不跳、不露语法；表格按格编辑、可拖列宽；任务方框可点。
还没做：表格增删行列；正文含列表 / 代码的引用与 callout、含 `<br>` 的段落与表格仍是「预览 + 源码编辑」。

## 范围

- **同一个控件**：段落、标题、列表项与任务、只含段落的引用、callout 的标题与正文、表格单元格、围栏代码块里的代码。没聚焦时就是没有光标的同一个控件，点进去字的位置、字重、折行、块高都不变。
- **不露语法**：成对标记、`[[ ]]`、`](地址)`、`{.red}`、`\` 转义、行首 `# ` / `> `、代码围栏始终藏着，光标贴着也不露。⌘K 改链接时光标落进 `(地址)`，那段地址才显示。
- **光标与删除**：`←` `→` 跳过藏起来的字节；`⌫` / `⌦` 删看得见的字，删空一对标记时连标记一起删；光标不停在藏起来的 `# ` / `> ` 前面（⌘← 落在标题文字开头）。
- **折行**：按整行字形排版测宽（逐字测宽时孤立的 `，` 只算半个字宽，行尾的字会被挤出去裁掉）；中日文避头尾，`。` `，` `」` 不落到行首。
- **拖选**：在任何一段按下鼠标就放光标，直接拖动即可选字，不必先点进去。
- **↑↓**：按视觉行走，长段落里 ↓ 先在折行间移动；跨块时保持横向位置；表格里到上 / 下一行同一列；callout 标题与正文互通。
- **表格**：列宽来自分隔行 `-` 的个数（各列一样多时按内容估算），编辑中冻结，点击和打字都不改列宽；长文字格内折行；拖列边界调宽，比例写回分隔行。单元格里输入 `|` 写成 `\|`，换行写成空格；⏎ 下一行，Tab 下一格。列太多放不下时表格横向滚动。
- **任务**：方框点一下在 `[ ]` 与 `[x]` 间切换，不进编辑态；勾上的任务淡色加删除线。
- **callout**：浏览与编辑同一个外框；折叠按钮在两种状态下都在，Tab 可以够到；标题为空时显示默认标题；标题里 ⏎ 到正文，正文最后一个空行再 ⏎ 离开。定位到折叠着的 callout 会展开。Lightbulb 等图标补进资源包（此前画成空白）。
- **反链面板**：来源片段里的 `==高亮==` 与 `{.red}` 按预览渲染，不再露出标记。

## 自动化

新增 8 项回归（`editor::layout_tests` 7 项、`presenter::tests` 1 项），并改写与旧双渲染器绑定的用例。全量 **553 项通过**（app 317、链接绘制集成 17、core 162、往返 5、index 51、反链计数集成 1）。

- `clicking_into_any_text_moves_nothing`：示例笔记里的每一段文字（标题、段落、列表、任务、单元格、引用、callout 标题与正文）逐个点进去，所有块的外框都与浏览时相等。
- `dragging_in_another_block_selects_text_right_away`：编辑第一段时在第二段按下并拖动，直接选中第二段的文字。
- `task_boxes_toggle_in_place`：点方框写入 `[x]`，不进编辑态，块不挪动。
- `typing_in_a_cell_stays_in_the_cell`：单元格里输入 `a|b` 得到 `a\|b`，控件仍属于那张表。
- `focused_text_never_shows_markdown`：光标放在 `[[`、`|`、`]]`、`](url)`、`{.red}`、`**` 上，这些字节都不占宽度。
- `every_visible_glyph_is_drawn_inside_the_text_area`：一段混排粗体、代码、链接、颜色的中文，在 560–860 宽度下每个字都画在控件里面。
- `arrow_keys_follow_visual_rows_and_table_columns`：↓ 在折行段落里先换行；表格里 ↓ 到下一行同一列。
- `fence_body_is_the_code_between_the_fences`：代码块只编辑围栏之间的代码。

```sh
cargo test -p aero-app --bin aero layout_tests
cargo test -p aero-app -p aero-core -p aero-index
```

## 已知限制

- 行内代码与正文同字号（等宽字体），不再像旧预览那样缩小到 0.875。
- 文本控件右侧给光标留 10 px，正文比旧预览窄 10 px 折行。
- 表格增删行列、合并单元格还没做；正文含列表、代码、嵌套引用的 callout 与引用，含 `<br>` 的段落与表格，仍是预览 + 源码编辑。
