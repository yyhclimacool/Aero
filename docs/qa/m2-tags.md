# M2 标签补全验收

日期：2026-09-17。

## 功能范围

- 非行首且空格 / tab 后输入 `#` 弹出候选菜单。支持中文、大小写不敏感的模糊匹配、`rust/cli` 这类分级标签，最多展示 8 条。
- 按使用篇数降序、同频按标签名排序，每条显示篇数。同篇重复出现或同时出现在正文与 front matter 只计一次；标签统一小写，不额外生成未实际使用的祖先标签。
- `↑↓` 循环选择，`⏎` / `Tab` / 鼠标插入，`Esc` 只关闭菜单；无匹配时保留用户输入，Enter / Tab 沿用普通编辑行为。插入不额外添加空格，可以一次撤销 / 重做。
- 已有标签中间编辑时替换完整标签，保留后面的标点；确认后光标位于标签末尾。引用 / callout、表格内可用；Markdown 标题、代码、数学、转义文本、URL、属性、wikilink 锚点等沿用索引规则排除。
- 候选后台加载；加载 / 失败不会当成空结果。移动光标或选区、退出编辑、打开其他面板、撤销 / 重做、重载、改名时关闭菜单，过期请求不能恢复旧菜单。IME 预编辑不写入文档，也不确认候选。
- 当前笔记使用内存中的未保存标签替换其索引计数；正在补全的半成品标签不作为已有候选。启动同步中或索引不可用时枚举磁盘笔记，遵守 vault 忽略规则。

## 标签目录

SQLite 元数据增加 `note_tags(note_id, tag)`，每篇 / 每个标签唯一。包含只有 front matter 而没有正文块的笔记。笔记指纹与标签更新在同一个事务里，标签写入失败时回滚两者；仅更新时间戳不会丢失标签。保存 / 外部修改、重命名和删除分别更新或清除目录。

元数据 schema 从 3 升为 4，沿用现有缓存版本策略：首次启动自动重建元数据与全文索引，后续按文件指纹增量维护。迁移不修改 Markdown；重建期间补全从磁盘读取。
