# M2 标签页与窗口外框验收

更新日期：2026-09-23。对应 [UI 设计 2.1 / 2.3 / 4.1 / 14](../ui_design.md) 与 [方案决策 21](../project_plan.md)。

已交付：多标签页、按三栏对齐的标题栏、编辑区顶部的路径、带收藏的资源管理器、重写的三栏布局与分割线。
还没做：`⌘[` / `⌘]` 浏览历史、钉住标签页、分栏、vault 切换器、资源管理器里的新建文件夹。

## 范围

- **标签页**：每篇文档一页。打开已打开的笔记就切过去；当前是空白的「新标签页」就放进这一页；否则在当前标签右边新开。搜索 ↑↓ 预览共用一个预览页（标题斜体），⏎、编辑或双击标签后留下来。`+` / ⌘T 开空白页（新建笔记、打开笔记、关闭标签页三个入口）。⌘W 关闭并停在右边那页，关掉最后一页留一张空白页；⌘⇧T 重开；⌘⇧[ ] 或 ⌃⇥ / ⌃⇧⇥ 切换；⌘1–8 第 n 页、⌘9 最后一页；中键关闭；拖动排序。命令面板另有关闭其他标签页。
- **没显示的页**：保留自己的编辑器（撤销、滚动），照常自动保存、接文件监听；切走时立刻落盘并进索引，切回时先检查外部修改。重命名、关闭 / 切换 vault、退出要求每页都能落盘，有一页保存失败就否决，那页的内容还在。
- **会话**：打开的标签页与当前页按 vault 记在 `state.toml`，重启恢复；只加载当前页，其余切到才读盘。已经不在的笔记跳过。
- **标题栏**：左侧栏上方 文件 / 搜索 / 标签 与折叠按钮，中间标签条与 `+`，右侧面板上方 反链 / 大纲 与折叠按钮；收起的一侧只留折叠按钮。点搜索切到搜索视图并聚焦输入框。按钮悬停提示带快捷键。
- **路径**：`vault › 文件夹 › 笔记.md`。点文件夹在树里展开并选中，点笔记名定位到笔记，点 vault 名切回文件视图；右端 ☆ 收藏。
- **资源管理器**：标题行（新建笔记、全部收起、定位当前笔记）、收藏分区、vault 名与路径、目录树，一起滚动，两个分区都可折叠。文件夹展开 / 收起用不同图标；打开在某个标签页里的笔记左边有点；行尾悬停出现 ☆；右键加了「在新标签页打开」「收藏 / 取消收藏」；⌘ 点击、中键在新标签页打开。收藏随改名、移动走，移进废纸篓时移除，外部删掉的显示删除线。
- **三栏与分割线**：两侧宽度固定，窗口变化只改编辑区；放不下时先压右侧面板再压左侧栏，编辑区至少 360 px，窗口放大后原样回来。拖动时整窗保持调整光标、编辑区不响应悬停；拖多少宽多少；往里拖过最小宽度 60 px 收起、同一次拖回来展开，收起状态松手后下次展开回到拖之前的宽度；双击复位。宽度与折叠状态记在 `state.toml`。
- **顺带修掉**：左栏收起后拖右侧分割线，面板直接跳到 480 上限（原来的比例分配把收起的那栏宽度也算进去）；窗口缩放时两侧按比例变宽；状态栏一直被挤出窗口看不到；「新建笔记」「新建 Vault」两个图标没打进资源包、画成空白；定位高亮在外部重载后落到别的块上。

## 已知限制

- 标签条放不下时各页先压到 84 px，再横向滚动；没有下拉的标签列表。
- 恢复会话不记滚动位置和光标，切到那页时从顶部开始。
- 收藏只收笔记，不收文件夹；收藏分区不能拖动排序。
- 拖分割线时指针离开窗口，宽度停在离开前的位置，回到窗口里继续跟随。
