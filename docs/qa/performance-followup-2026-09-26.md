## 五项问题的处理

| 问题 | 完成后的行为 |
| --- | --- |
| 重命名提交在主线程校验、备份和改写全库 | 完整事务在后台执行，保留原有校验、恢复副本与回滚。提交期间暂停编辑器 I/O；后台读回改写后的正文，换路径并装回正文后恢复界面。期间收到的文件事件合并后继续处理，文件树后台重扫。 |
| 附件导入、脏页关闭同步写盘 | 附件后台读取和创建，连续导入保持顺序与撤销粒度。关闭页等待最新版本保存成功，失败则保留页面。原生退出保存屏障等待已接受的写入，再保存较新的快照，避免两次保存竞争。 |
| 快速打开前台全库扫描和排序 | 目录、标题、别名后台加载；大目录匹配经防抖在后台计算，用有界候选堆保留结果。通过请求代次丢弃过期回复，加载中确认不会错误新建。 |
| 切库在主线程等待索引结束 | 普通切库、关闭和退出先异步保存，再后台等待索引任务、刷新并释放原生句柄。完成前保留会话且阻止隐藏输入；原生强制退出继续保留安全兜底。 |
| 普通图片缺少缓存和任务预算 | 图片宽度向上归入 64 逻辑像素档位；非 PDF 缓存 64 项、PDF 12 项，共享估算 128 MiB 位图软预算。渲染并发 2，派发队列最多 32；过期尺寸不继续排队，过期回调不能复活已淘汰结果。 |

当前帧可见资源受保护，可能临时超过缓存软预算，以免发生淘汰后反复渲染；离开可见范围后按最近使用顺序淘汰。该预算不是整个应用的内存上限，也不包含磁盘缓存。

另外补齐了长列表增删后的滚动锚点保持，并修正了续作中未接齐的保存屏障、重命名调用和测试夹具。索引启动线程的状态变更由 GPUI 进度任务唤醒等待者，避免原生线程直接唤醒受线程约束的测试调度器。
