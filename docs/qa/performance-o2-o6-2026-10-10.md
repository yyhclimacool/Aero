# O2–O6 剩余优化验收（2026-10-10）

对应 [project_plan 19.1](../project_plan.md#191-性能优化实施计划2026-10-08)。本轮延续 2026-10-08 的 O1 / O2 首批改动，完成剩余开发范围。参考 Zed 的调度与快照机制，继续使用 Aero 的 Rope、Comrak、GPUI 和现有索引。

## 实现与回退

- **O2 文件操作**：新建、日记、Finder 批量导入、附件改名和删除由后台执行；先完成编辑器保存，再冻结文件 I/O，完成后恢复。连续新建有序排队，关库等待已接受操作。原生退出保留 join guard。命名使用 create-only 发布，导入失败保留已有成功结果并反馈错误。附件改名共用 `RenamePlan` 的前后解析、指纹校验、恢复副本与失败回滚，不覆盖外部变化。操作期间保留文件监听事件，并作废尚未完成的旧标签加载。
- **O3 解析**：输入先尝试最多 64 KiB 的安全局部段落解析；文档达到 256 KiB 后，全量回退解析使用后台快照，每个编辑器最多一个任务。按文档版本、路径和会话代次装回；连续输入丢弃旧结果，补做最新快照。聚焦输入保留，语法完成后更新块身份与输入行为，组合输入期间不主动换控件。结构命令仍可同步校准有效解析版本。
- **O4 派生状态**：Document 提供可消费的编辑摘要，单位与嵌套列表范围按与 Anchor 一致的偏置漂移。局部解析成功时保留单位、ID 索引及视口；全量解析后比较结构与上下文，无变化时保留布局。结构变化继续使用全量回退并按已有行身份保留高度。`apply_parse` 不再重复扫描全文统计引用括号。
- **O5 目录**：每个 Vault 共用版本化目录快照，独立于 FTS 启动与可用性。文件树、快速打开、补全与 Resolver 共用笔记元数据及附件目录。保存 / 路径事件重读变动笔记，新增路径校验忽略规则，目录 / 忽略规则变化做全量校准；全量校准复用未变文件的元数据。多个后台请求合并，构建中收到更新则拒绝旧版本。未变候选复用预处理字符数据。
- **O6 匹配**：标题、路径、aliases、标题片段与块候选预处理 Unicode 小写字符，最近访问排名预建映射。共享 Top-K 算法保留 12 / 8 项，排序与原语义一致。256 项以上在后台计算；每候选检查取消标记，替换查询或关闭菜单停止旧计算。快速打开保留 100 ms 合并窗口，Wikilink 使用 40 ms；结果按请求代次校验。筛选期间方向键与 Enter 延后应用。

## 验收边界

结构命令的同步校准、解析结果的块树装回及结构变化仍可能整理全部块 / 单位。Anchor 与单位位移仍为 O(块数)，没有引入 Zed 的增量语法树或树形 Anchor。嵌入扫描暂时独立于主解析产物。原生 IME 人工矩阵、参考机器 GUI p99 / 帧率 / 内存预算、10k / 100k 磁盘库端到端测量与稳定的 20% 性能门禁仍需单独验收。没有据微基准宣布 M1 性能预算整体达标，也没有执行打包或正式公证。
