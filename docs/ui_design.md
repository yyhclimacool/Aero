## 1. 设计原则

1. **文档是主角。** 窗口 chrome 越少越好；所有面板可折叠，专注模式下只剩正文。参考 Zed 的克制而不是 Notion 的装饰。
2. **键盘优先，鼠标可达。** 每个操作都有快捷键或命令面板入口；鼠标路径不超过两步（悬停出现、点击执行）。
3. **源码够得到，默认不挡路。** 普通编辑不露出 Markdown 标记；当前块或整篇可以打开源码，渲染失败的块退化为源码。不做应用级的第二种编辑器。细则见 `project_plan.md` 9.1。
4. **状态可见、不打扰。** 保存、索引、冲突、AI 待审阅变更全部走状态栏与非模态横幅/toast，不用模态对话框。唯一的模态是确认性破坏操作。
5. **不撒谎的降级。** 网络不可用、渲染器失败、索引未就绪时，UI 明确说明而不是静默变慢或空白。
6. **中文排版是一等公民。** 字体回退、行高、标点、IME 候选框位置在每个组件设计时就考虑，而不是最后修补。
7. **少设置，多默认。** 设置页只放会被反复调整的项；其余进 `.aero/config.toml`。

## 2. 信息架构与窗口布局

### 2.1 主窗口

当前布局（2026-09-26）：

```text
┌──────────────┬─────────────────────────────────┬─────────────┐
│ 文件 搜索 标签│ [笔记一 ×] [笔记二]  +           │ 反链 大纲   │
├──────────────┼─────────────────────────────────┼─────────────┤
│ 文件树       │ vault › 文件夹 › 笔记.md      ☆ │             │
│ 收藏         │                                 │ 预留面板    │
│              │ 笔记正文           大纲导航浮层 │ （暂为空）  │
│              │                                 │             │
│              │ 文末反链                        │             │
├──────────────┴─────────────────────────────────┴─────────────┤
│ vault · 保存状态 · 索引进度 · 字数                           │
└──────────────────────────────────────────────────────────────┘
```

- **左侧栏**：文件 / 搜索 / 标签三个视图。默认宽 260 px，可拖拽 200–480 px；`⌘\` 折叠。设置入口已接入，vault 切换器仍为规划。
- **编辑区**：顶部是路径与收藏，下面是文档；反链在文末，大纲使用编辑区导航浮层。正文列宽与字体的自定义设置仍待实现。
- **右侧面板**：保留布局与折叠控制，当前内容为空；默认宽 300 px，可拖拽 220–480 px，`⌘⇧\` 折叠。属性 / 待审阅变更 / 图谱尚未接入。
- **状态栏**：显示 vault、保存状态、索引进度与字数；MCP 状态仍为规划。

两侧宽度固定，窗口调整主要改变编辑区；放不下时先压右侧，再压左侧，尽量为正文保留 360 px。分割线拖过最小宽度 60 px 可收起，拖回可展开；双击恢复默认宽度。拖动期间暂停编辑区悬停与选字。

两侧宽度与折叠状态按应用保存；标签页与收藏按 vault 记忆在应用数据目录，不写入笔记库。

### 2.2 专注模式（规划）

`⌘⌥\`：隐藏两侧面板、标签页与状态栏，只留正文与一条 2 px 高的保存/冲突指示。再按一次或 `Esc`（浏览态下）退出。

### 2.3 标题栏

macOS 原生交通灯 + 自绘标题栏，与下面三栏对齐：左侧是 文件 / 搜索 / 标签 和折叠按钮，中间是标签页与 `+`，右侧保留 反链 / 大纲 和折叠入口。反链入口滚动到文末引用区，大纲入口显示编辑区导航浮层；不再把它们放进右侧面板。标题栏空白处可拖动窗口、双击缩放。

**标签页：每篇文档一个标签页。**
- 打开笔记（文件树、快速打开、搜索 ⏎、反链、链接、新建、日记）：已经在某个标签页里就切过去；当前是空白的「新标签页」就放进这一页；否则在当前标签右边新开一页。
- 搜索结果里 `↑↓` 预览的笔记放进一个预览页（标题斜体），继续 `↑↓` 在同一页里换；`⏎`、编辑或双击标签后它变成普通页。
- `+` / `⌘T` 开空白的「新标签页」：新建笔记（⌘N）、打开笔记（⌘P）、关闭标签页（⌘W）三个入口。
- 标签页显示笔记标题，悬停显示路径；未保存修改时标题左侧有一个小圆点（正常情况下 500 ms 内会消失），保存失败是红点。当前页和悬停的页显示 ×。
- `⌘W` 关闭（停在右边那页；关掉最后一页留一张空白页），`⌘⇧T` 重开，`⌘⇧[` / `⌘⇧]` 或 `⌃⇥` / `⌃⇧⇥` 切换，`⌘1–8` 跳到第 n 页、`⌘9` 最后一页。中键点标签关闭，拖动标签排序。
- 中键或 `⌘` + 点击文件在新标签页打开；右键菜单也有「在新标签页打开」。
- 没显示的标签页保留自己的编辑器（撤销历史、滚动位置），照常自动保存、检查外部修改；切走时立刻落盘并进索引，切回来先看一眼磁盘。恢复会话时只记路径，切到那一页才加载。
- 分栏（左右并排两篇）列入 M4。

**路径**：编辑区顶部一行 `vault › 文件夹 › 子文件夹 › 笔记.md`（参考 marka）。点文件夹在文件树里展开并选中它，点笔记名定位到笔记，点 vault 名切回文件视图；右端 ☆ 收藏 / 取消收藏当前笔记。

## 3. 导航模型

### 3.1 Vault

- 一个窗口对应一个 vault。侧栏底部的 vault 切换器列出最近打开的 vault，选择即在当前窗口切换。
- 首次运行见第 11 节。

### 3.2 快速打开（`⌘P`）

居中弹出的模糊搜索框，搜索范围是笔记标题、别名、路径。

```text
┌────────────────────────────────────────────┐
│ 🔍 ripg                                    │
├────────────────────────────────────────────┤
│ ripgrep                        rust/       │  ← 最近打开优先
│ Rust CLI                       rust/       │
│ ripgrep 性能笔记                projects/  │
├────────────────────────────────────────────┤
│ + 新建 "ripg"                    ⌘⏎        │
└────────────────────────────────────────────┘
```

- `⏎` 打开，`⌘⏎` 新标签页打开，`⌥⏎` 在文件树中定位。
- 无匹配或按 `⌘⏎` 时新建同名笔记（位置规则见 3.5）。
- 空输入时显示最近打开的 10 篇。

### 3.3 浏览历史

`⌘[` / `⌘]` 后退/前进，历史按标签页记录，粒度到"笔记 + 滚动位置/块"。点击链接、搜索结果、反链都入栈。

### 3.4 日记

`⌘⇧D` 打开今日日记（`daily/YYYY-MM-DD.md`，不存在则按模板创建）。文件树中 `daily/` 目录默认按日期倒序。

### 3.5 新建笔记的位置规则

依次：当前文件树选中的文件夹 → 当前打开笔记所在文件夹 → vault 根。从未解析链接创建时，放在**链接所在笔记的文件夹**。规则可在设置中改为"固定目录"。

## 4. 左侧栏

### 4.1 文件树

```text
▾ daily                         ← 文件夹，默认按名称排序，daily/ 例外倒序
   2026-09-14
   2026-09-13
▾ rust
   cargo
 ● ripgrep            📎2        ← 当前打开；悬停显示附件数
   tokio
▸ projects
```

资源管理器从上到下（参考 marka）：视图标题行（新建笔记、全部收起、定位当前笔记）→ 「☆ 收藏」分区 → vault 名与路径 → 目录树。三部分一起滚动，收藏分区与 vault 分区都可以折叠。

- **收藏**：在笔记行上悬停点 ☆、右键「收藏」、路径行右端的 ☆ 或命令「收藏 / 取消收藏当前笔记」。收藏按收藏先后排，显示笔记名与所在目录；笔记改名、移动时跟着走，移进废纸篓时移除，在外部被删的显示为删除线。按 vault 记在应用数据目录。
- **打开状态**：文件夹展开时是打开的文件夹图标，收起时是合上的；在某个标签页里打开着的笔记左边有一个点，当前那篇高亮。
- 只显示文件夹与 `.md`（扩展名隐藏）。`*.assets/` 目录默认隐藏，所属笔记悬停时显示 📎 与附件数，点击展开为子项；视图菜单可切换"显示附件目录"。**已实现**：📎 与附件数（常显，非悬停）、点击展开 / 收起附件子行、附件行双击用系统应用打开、没人引用的附件标「未引用」；视图菜单开关未做。
- 其他非 `.md` 文件默认隐藏，视图菜单可显示（只读，双击用系统应用打开）。
- 键盘：`↑↓` 移动，`→/←` 展开/折叠，`⏎` 打开，`⌘⏎` 新标签页打开，`F2` 重命名，`⌘⌫` 移到废纸篓，`Space` 快速预览浮层。
- 右键菜单：在新标签页打开、收藏、新建笔记、新建文件夹、重命名、移到废纸篓、复制链接 `[[...]]`、复制路径、在 Finder 中显示。**已实现**：在新标签页打开、收藏、重命名、移到废纸篓、复制路径、在 Finder 中显示。
- 拖放：树内拖动文件 / 文件夹至目录或明确的「Vault 根目录」落点，支持空目录并高亮可用目标；统一事务同步入链、相对出链和附件路径（见技术方案 11 节）。F2 / 右键重命名使用行内输入，Enter 提交、Esc / 失焦取消；冲突不合并、不覆盖。从 Finder 拖进来时，`.md` 复制进目标目录，其他文件要拖到某一篇笔记上，复制进它的 `.assets/`。
- 删除一律进系统废纸篓，不做自定义回收站。
- 排序：名称 / 修改时间；文件夹优先。
- `⌘⇧E` 在文件树中定位当前笔记。

### 4.2 搜索视图

`⌘⇧F` 打开并聚焦。当前提供「全文 / 混合」和「设置」，输入 150 ms 防抖后查询；结果按笔记分组、块级定位并高亮关键词，`↑↓` 预览，`⏎` 确认打开。

- 全文语法：`"短语"`、`+必含`、`-排除`、`#标签` / `tag:标签` / `-#标签`。父标签匹配子标签，多个包含标签必须同时命中。`path:` 语法与搜索历史仍未实现。
- 搜索索引在保存成功或磁盘变化后更新，没有覆盖未保存正文的内存 overlay。
- 「混合」先显示全文结果，再补充本地语义并融合排序；迟到结果不会改变用户选中的块，模型未就绪或出错时保留全文结果。
- 「设置」打开「搜索与隐私」，提供默认关闭的下载许可和语义开关、显式模型下载、进度与暂停控制。使用步骤与资源限制见 [本地语义搜索](semantic-search.md)。

### 4.3 标签视图

嵌套标签树（`rust/cli` 显示为 `rust` 下的 `cli`），每项带计数。点击 = 在搜索视图执行 `tag:#rust/cli`。右键：重命名标签（全库替换，M4）。

- **当前实现（2026-09-22）**：左侧栏第三页「标签」已接上。树按 `/` 分级、默认展开、点三角折叠；计数按「点这项会搜到的篇数」（父含子）。点击切到搜索并立刻执行 `tag:#…`。目录读索引，同步未完成时扫磁盘。尚未实现：右键改名、正文 / 属性条点标签跳搜索。详见 [标签视图验收](qa/m2-tag-view.md)。

## 5. 编辑区

### 5.1 文档结构

```text
┌────────────────────────────────────────────────────────┐
│ ripgrep                                    3 反链  ⋯   │  ← 标题行
│ tags: rust · cli   created: 2026-09-14   + 属性        │  ← 属性条（折叠）
│                                                        │
│ # ripgrep                                              │  ← 正文（块列表）
│ 安装：                                                  │
│ …                                                      │
└────────────────────────────────────────────────────────┘
```

- **标题**：显示 front matter `title`，没有则显示文件名。点击可编辑：有 `title` 键时按事务修改属性并同步失效的入链，否则重命名文件并同步链接。只有此入口触发 title 跨文件改写；直接编辑 YAML / 外部修改只刷新解析和索引。
- **属性条**：front matter 以只读 chips 展示；点击任意 chip 或 "+ 属性" 展开为源码编辑（M1）；结构化编辑（键值表格）列入 M4。没有 front matter 时属性条不显示，`⌘⇧,` 或块菜单可添加。
- **反链计数**：点击打开右侧反链面板。
- **⋯ 菜单**：在 Finder 中显示、复制链接、复制路径、导出、移到废纸篓、文档统计。

### 5.2 聚焦块的呈现

**硬性要求（`project_plan.md` 9.1，2026-09-23）**：用户不感知 Markdown 语法。

1. 编辑态与浏览态同一副样子：不冒出不相干的元素，不露出任何一截语法（`**`、`[[`、`](地址)`、`}`、`{.red}`、`# `、`> `、代码围栏）。⌘K 改链接时显示地址是唯一例外。
2. 点进任何一块零跳变：所有块的位置、高度、折行不变，字号、字重不变，只多出光标。
3. 表格列宽可拖动调整；点击某格、在格里打字都不改列宽；格内长文字自动换行。
4. 在任何一块按下鼠标即可拖选，不必先点进去。
5. `> [!tip]`、`> [!note]` 等 callout 两种状态是同一个外框，不跳变。
6. 任务方框直接点击勾选 / 取消，不进编辑态，不跳变。

做不到的内容保持「预览 + 源码编辑」，在 `project_plan.md` 9.1 列出，不半藏半露。

**默认观感以 `project_plan.md` 9.1 为准（2026-09-23）。** 浏览与编辑是同一副样子：段落、标题、列表与任务、引用、callout 的标题与正文、表格单元格、代码块里的代码，都由同一个文本控件画，点进去只多出光标。语法标记始终藏着。块菜单「编辑源码」只打开当前块；视图菜单「查看源码」打开整篇；「聚焦时显示源码」是偏好，打开后聚焦块回到源码。选区工具条不含字体族、字号、字间距、段距。数学仍在弹窗里编辑源码。

- 点击一段文字，光标就落在点击处，字的位置、粗细、折行都不变；按下后直接拖动即可选字，不必先点一下。`**粗体**` 是粗体、`[[笔记|文字]]` 是链接文字、`# 标题` 不露出井号，光标贴着也不露。⌘K 改链接时，光标落进地址那段才显示地址。
- `←` `→` 跳过藏起来的标记；`⌫` / `⌦` 删的是看得见的字，删空一对标记时连标记一起删，不留下 `****`。光标不会停在藏起来的 `# ` / `> ` 前面。
- 没编辑的那段里点链接是打开链接，悬停出预览；编辑中的那段里点链接是放光标。
- 表格：点哪格改哪格，列宽不因为点击、打字而变，长文字格内折行。拖列边界调宽度（比例写回分隔行）。⏎ 下一行，Tab 下一格。
- callout：标题和正文分别编辑，外框、图标、折叠按钮不变；标题里 ⏎ 到正文，正文最后一个空行再 ⏎ 离开 callout。
- 光标离开块（点击别处、`↑↓` 移出、`Esc`）不换控件，只是没有了光标。
- 复选框直接点击切换（写回 `[ ]` ↔ `[x]`），不进编辑态；勾上的任务淡色加删除线。
- 数学块 / mermaid 块进入源码态时，源码下方保留一个实时预览（300 ms 防抖），写公式时不需要来回切换（M3）。

### 5.3 块 gutter

悬停任意块时，左侧出现两个控件：

```text
   ⠿ +   安装 ripgrep 的方法有两种…
```

- `⠿` 拖拽手柄：拖动重排；点击进入块选中态并打开块菜单。
- `+`：在此块下方插入新块并打开 `/` 菜单。
- 块菜单条目（`⠿` 点击 / 右键 / `⌘/`）：转换为 ▸、颜色 ▸（见 7.7）、复制块链接、复制块、添加/复制 `^id`、删除；图片块另有宽度预设。
- **当前实现（2026-09-23）**：`⠿`、右键和 `⌘/` 打开这块菜单。颜色从「颜色 ▸」进入 7.7。拖动 `⠿` 在本篇内重排：半透明预览、2 px 插入线；列表项右侧 24 px 把插入线缩进，松手后成为子项。`Esc` 取消。松手落位并高亮 300 ms。不跨笔记。

## 6. 块编辑交互状态机

```text
                    点击块 / ⏎ / 输入
   ┌──────────┐ ─────────────────────▶ ┌──────────┐
   │  浏览态   │                        │  编辑态   │ ◀─┐
   │ (无焦点)  │ ◀───────────────────── │ (光标在块内)│   │ Esc 退出菜单
   └──────────┘        Esc ×2          └──────────┘   │
        ▲                                 │   ▲       │
        │ Esc                         Esc │   │ ⏎ / 输入
        │                                 ▼   │
   ┌──────────┐      ⇧↑↓ / ⌘A ×2      ┌──────────┐    ┌──────────┐
   │  拖拽态   │ ◀──── 拖动手柄 ─────── │ 块选中态  │    │  菜单态   │ ( / [[ # 弹层 )
   └──────────┘                        └──────────┘    └──────────┘
```

**编辑态**（光标在某个 Leaf Block 内）

- 字符级选区限于当前块；`⇧↑`/`⇧↓` 越过块边界时整个选区升级为块选中态。
- `⏎` 段落末新建段落；段落中间 `⏎` 拆分块；`⇧⏎` 软换行；空列表项 `⏎` 退出列表；`⌫` 在块首合并到上一块（保留上一块类型）。
- `↑`/`↓` 在首行/末行时移到相邻块，保持视觉列位置。
- `⌘A`：第一次选中当前块全部文本，第二次选中全部块（进入块选中态）。
- `Esc`：进入块选中态（当前块被选中）。

**块选中态**（一个或多个整块高亮，无文本光标）

- `↑`/`↓` 移动选中；`⇧↑`/`⇧↓` 扩展；`⌘⇧↑`/`⌘⇧↓` 移动块。
- `⏎` 进入编辑态（光标在块末）；直接输入字符也进入编辑态并在块末插入。
- `⌫`/`⌦` 删除选中块（可撤销）；`⌘C`/`⌘X` 复制/剪切为 Markdown 文本；`⌘V` 在选中块之后粘贴。
- `⌘D` 复制块到下方；`⌘/` 打开块菜单；`⌘⌥0–8` 转换类型；`Tab`/`⇧Tab` 调整缩进。
- `⌘⇧H` 给所有选中块应用上次使用的颜色（7.7）；块菜单 → 颜色 可选任意颜色。
- `Esc` 回到浏览态。

**拖拽态**

- 拖动 `⠿` 出现半透明块预览；目标位置显示 2 px 插入线；拖到列表项右侧 24 px 区域时插入线缩进，表示成为子项。
- `Esc` 取消；松手落位并短暂高亮 300 ms。

**菜单态**（`/`、`[[`、`#`、`![[`、`[[note#^` 弹出的补全层）

- `↑↓` 选择，`⏎`/`Tab` 确认，`Esc` 关闭并保留已输入字符，继续输入实时过滤。
- 光标移出触发位置或输入空格（`#` 标签例外：空格结束标签）自动关闭。

## 7. 输入、补全与粘贴

### 7.1 `/` 块菜单

在块首或空格后输入 `/` 触发，模糊过滤：

```text
/ 代
┌──────────────────────────┐
│ ⌗  代码块          ⌘⌥8   │
│ ∑  数学块                │
│ ⋮  callout ▸             │
└──────────────────────────┘
```

条目：文本、标题 1/2/3、无序列表、有序列表、任务、引用、callout（子菜单：note/tip/warning/danger/info/question/example/quote）、代码块（随后选语言）、数学块、mermaid、分割线、表格（3×3 骨架）、图片/附件（文件选择器）、嵌入笔记、今天日期、属性、颜色（`/红色`、`/蓝色背景`、`/默认颜色` 直接命中，给当前块上色，见 7.7）。

在非空块上使用 `/` 菜单选择块类型 = **转换**当前块（编辑源码前缀），不新建。

### 7.2 链接与标签补全

- `[[` 弹出笔记选择器（标题/别名/路径模糊匹配，最近优先）；`⏎` 插入 `[[名称]]`，`⇧⏎` 插入 `[[名称|别名]]` 并选中别名待输入；无匹配时 `⏎` 插入未解析链接。
- `[[名称#` 列出该笔记的标题；`[[名称#^` 列出该笔记的块（渲染前 60 字），选中即写入 `^id`（若目标块尚无 id 则生成）。
- `![[` 同上，但同时列出附件（图片、PDF）。
- `#` 在非行首、前面是空格时弹出标签补全（已有标签按频次排序）；行首 `#` 是标题，不触发。
- `⌘K`：有选区时把选区变成 `[文本](url)` 并选中地址待输入（剪贴板是 URL 时自动填入）；无选区时插入 `[[]]`，光标放中间并弹出笔记选择器。光标 / 选区位于已有行内链接时只选中其地址，保留文字与标题；已有 wikilink 使用笔记补全或选中目标。可从「编辑」菜单与命令面板调用。当前实现及限制见 [行内链接验收](qa/m2-inline-links.md)。

### 7.3 自动配对与续行

- 成对输入：`**`、`==`、`` ` ``、`$`、`[[`→`]]`、`(`、`"`。在已配对的右侧输入相同字符时跳过而不重复。
  已实现逐键配对、跳过自动生成的闭合符、空配对退格删除与撤销 / 重做；只跟踪当前编辑中的自动配对，粘贴、选区替换和输入法提交保持原文。上下文规则及验收见 [自动配对记录](qa/m2-pairs.md)。
- 列表续行：`- `、`1. `、`- [ ] ` 在 `⏎` 时延续，有序列表自动递增；连续两次 `⏎` 退出列表。
- 引用续行：`> ` 延续，空行两次退出。
- `- [ ]` 输入时立即显示为复选框（渲染在源码态也生效）。

### 7.4 行内格式快捷键

`⌘B` `**`、`⌘I` `*`、`⌘E` 行内代码、`⌘⇧S` `~~删除线~~`：有选区时包裹，无选区时插入成对标记并把光标放中间；对已包裹的选区再次按下则取消包裹。`⌘K` 插入或编辑链接，遵循 7.2 的选区 / 已有链接 / 笔记补全规则。

`⌘⇧H` 应用**上次使用的颜色**（与 Notion 一致）；从未用过颜色时等于黄色背景，即 `==高亮==`。对已带同一颜色的选区再次按下则去掉该颜色。

当前已实现粗体、斜体、行内代码、删除线与黄色高亮的包裹 / 取消、空标记插入、编辑菜单及命令面板入口，见 [行内格式验收](qa/m2-inline-format.md)。`⌘⇧H` 暂使用黄色高亮；其他颜色及上次颜色记忆随 7.7 实现。

### 7.5 粘贴规则

- 纯文本：按 Markdown 解析成块插入。多行文本包含 Markdown 语法时保持原样。
- 图片（剪贴板位图或文件）：写入当前笔记 `.assets/`，插入 `![[<ulid>.png]]`。**已实现**：位图用 ULID 命名，Finder 复制来的文件保留原名、重名追加 `-2` 而不覆盖。
- 文件：复制到 `.assets/`，图片插入 `![[...]]`，PDF 插入 `![[x.pdf]]`，其他插入普通链接。**已实现**；剪贴板里同时有文字时按文字粘贴（浏览器复制的内容通常要的是文字）。
- 单独一行的 URL：插入原文；渲染态显示为链接卡片（M4）。
- HTML（从浏览器复制）：M1 按纯文本处理；M4 转 Markdown。
- `⌘⇧V` 强制按纯文本粘贴，不做任何转换。
- 在选中的文本上粘贴 URL：变成 `[选中文本](url)`。

### 7.6 拖放到编辑区

从 Finder 拖入图片/PDF/文件 = 7.5 的文件规则；从文件树拖入笔记 = 插入 `[[笔记]]`（按住 `⌥` 插入 `![[笔记]]`）。**已实现（2026-09-22）**：拖到编辑区时，Finder 文件复制进当前笔记的 `.assets/`（图片 / PDF 插入嵌入，其他插入链接，文件夹跳过）；文件树里的笔记插入 `[[路径]]`，按住 ⌥ 插入 `![[路径]]`。拖到文件树上的 Finder 导入仍未做。

### 7.7 颜色

给一段文字或一个块上色，交互对齐 Notion；文件中的表示见 `project_plan.md` 6.3.10（属性列表 `{.red}` / `{.bg-blue}`）。

**入口**

- 文字颜色：选中文字 → 浮动工具条 `A ▾`；或 `⌘⇧H` 直接应用上次的颜色。
- 块颜色：块菜单 → 颜色；块选中态 `⌘⇧H`；`/` 菜单输入颜色名（`/红色`、`/蓝色背景`）；文字选区覆盖整块时，颜色菜单顶部多出"应用到整块"开关。
- 多块选中时对所有选中块生效；已有不同颜色的块一律覆盖为新选择。

**颜色菜单**

```text
┌──────────────────────────────────┐
│ 上次使用    A 蓝色背景     ⌘⇧H   │
├──────────────────────────────────┤
│ 文字                             │
│  A 默认  A 灰  A 棕  A 橙  A 黄   │
│  A 绿   A 蓝  A 紫  A 粉  A 红   │
├──────────────────────────────────┤
│ 背景                             │
│  A 默认  A 灰  A 棕  A 橙  A 黄   │
│  A 绿   A 蓝  A 紫  A 粉  A 红   │
└──────────────────────────────────┘
```

- 9 色 + 默认，文字与背景各一组，可以叠加（红字 + 黄底）；每个样本用真实颜色渲染 `A`。
- 菜单打开后可直接输入过滤（"蓝"、"bg"），`⏎` 应用，`Esc` 关闭。
- 当前选区/块已有的颜色显示选中标记；选"默认"移除该组颜色。
- 与调色板对齐：`gray brown orange yellow green blue purple pink red`，具体色值走 13.3 的 `content.*` 令牌，浅色/深色主题各一套，保证在两种主题下文字对比度都达到 AA。

**写回与显示**

- 选"黄色背景"写 `==文本==`；其他颜色写 `[文本]{.bg-blue}` / `[文本]{.red}`；选区恰好是一个 `**粗体**` 之类的行内元素时挂在元素后：`**粗体**{.red}`。
- 块颜色写在块末：`段落文本 {.bg-blue}`；标题 `# 标题 {.red}`；多行块独占一行，规则同 `^id`。
- 渲染态：文字色改前景色；背景色是带 2 px 圆角的底色，行内与 `==` 同样式；块背景铺满块矩形并含子块，左右各 padding 8 px。
- 源码态：`{.red}` 和 `[`/`]` 以淡色标记显示，颜色本身仍然生效，让人看得到"这段颜色是这么写的"。
- 全部颜色都不进入全文索引与语义索引；导出/复制为 Markdown 时原样保留。
- **当前实现（2026-09-23）**：写回、色值令牌、渲染态上色、`⌘⇧H`、颜色菜单、选区工具条、块菜单里的「颜色 ▸」、选区盖住整块时的「应用到整块」、源码态把 `[` `]` `{.red}` 洗淡、多行块颜色写在独占行，都已接上。详见 [颜色验收](qa/m2-colors.md)。

**不做的**

- 不做自定义色值（`{color=#ff0000}`）：调色板才能跟随主题；解析器遇到会保留但不渲染。
- 不做整篇文档的默认颜色；不做按标签自动上色。

## 8. 链接、反链与上下文导航

### 8.1 链接行为

- 已解析链接：实线下划线强调色；点击按 2.3 的标签页规则打开笔记，已有页面则切换过去。
- 未解析链接：虚线下划线、淡色；普通无候选笔记链接点击创建笔记（位置见 3.5）并打开，toast 提供"撤销"。歧义使用 warning 色虚线并提示候选，不创建文件。跨篇缺失 fragment 到悬停读盘才校验，目前不保证即时淡色。
- 悬停 500 ms 显示预览浮层；**当前实现（2026-09-22）**按笔记预览渲染这段 Markdown（标题、强调、callout、颜色都在），只读、可滚动。普通笔记大约前 300 个字符，`#标题` / `#^块` 只显示对应片段。同篇使用未保存文档，跨篇后台读盘。离开链接后有 150 ms 宽限以进入浮层，离开浮层后关闭；编辑器滚动 / 缩放 / 失焦 / 编辑 / 重载 / 删除会取消，generation 丢弃旧回复。视图菜单「链接预览」和命令面板可以改成「按住 ⌘ 才显示」或「关闭」（记在应用级 `state.toml`）。`⌘,` 设置对话框现已提供这项偏好，反链也已渲染富文本片段。
- 外部 URL：点击用系统浏览器打开；悬停只显示完整地址，不联网获取内容。
- 当前链接按 URL 区分 solid / dashed 样式并接收 hover 回调，来自仓库内 `forks/gpui-base` patch，不修改全局 registry。aliases 与 title 同级解析（优先级低于路径 / 文件名），`[[`、`⌘P`、全文搜索支持 aliases，候选仍显示原 title；补全写入经 resolver 验证的规范目标。

### 8.2 反链、大纲与规划中的上下文面板

## 10. 状态、通知与错误

### 10.1 状态栏

```text
Knowledge ▾ · 已保存 · 索引中 1,234/10,000 · 1,204 字 · MCP 1 · ⚠ 1
```

- **vault 名**：点击切换 vault。
- **保存状态**：`已保存` / `保存中…` / `冲突`（红）/ `只读`。点击显示上次保存时间与文件路径。
- **索引进度**：仅在索引进行中显示；点击弹出详情（元数据 / 全文 / 语义 各自进度，"暂停"、"重建索引"）。
- **字数**：当前文档；有选区时显示选区字数。中文按字计数，英文按词。
- **MCP**：连接的客户端数与待审阅计数；点击打开变更面板；服务未启动时不显示。
- **⚠**：本次会话的非致命错误数（渲染失败、抓取失败等），点击查看列表。

### 10.2 非模态横幅（文档顶部）

- **外部修改已自动合并**：蓝色，"此文件在外部被修改并已合并 · 查看差异 · 撤销合并"，10 秒自动消失。
- **冲突**：黄色，"此文件在外部被修改，且你有未保存的改动 · 查看差异 · 保留我的 · 使用磁盘版本"。磁盘版本已另存为 `<name>.conflict-<time>.md`，横幅说明其位置。不消失直到用户选择。
- **文件已删除**：红色，"此文件已在外部被删除 · 另存为… · 关闭"。文档内容保留可复制。
- **只读**：灰色，"没有写入权限"。

### 10.3 Toast（右下角）

用于可撤销的操作结果：已创建笔记、已移到废纸篓、已移动 3 个文件并更新 12 个链接、已应用 AI 变更。5 秒消失，带"撤销"。同时最多 3 条，多余的折叠为"还有 N 条"。

### 10.4 渲染与网络失败

- 渲染失败：块内显示源码 + 一行淡红色错误 + "重试"。
- 链接卡片抓取失败/离线：显示纯链接，无提示（不值得打扰）。
- 语义索引模型未下载：搜索视图的"语义"开关旁显示"下载模型（~200 MB）"按钮。

### 10.5 模态对话框（仅限以下）

- 移到废纸篓且笔记有非空 `.assets/`：询问是否一并移除。
- 重命名/移动将更新 N 个其他文件中的链接且 N > 20：确认。
- 重建索引。
- 退出时仍有写入进行中：等待或强制。

## 11. 首次运行与 vault 管理

不带命令行路径启动时恢复最近打开且目录还在的库，已经不在的条目跳过、不报错；首次运行或一个都恢复不了时停在库选择页。给了路径就直接打开那个库。「文件 → 关闭 Vault」也回到这一页。

```text
┌──────────────────────────────────────────┐
│                                          │
│              Aero                        │
│   本地优先的 Markdown 知识库              │
│                                          │
│   [ 打开文件夹作为 vault… ]               │
│   [ 新建 vault… ]  [ 查看示例库 ]          │
│                                          │
│   最近                                   │
│   ~/Knowledge                            │
│   ~/Projects/notes                       │
│                                          │
│   把文件夹拖到这里也可以                   │
└──────────────────────────────────────────┘
```

- 打开已有文件夹时说明将创建 `.aero/`（只含配置）与应用数据目录下的索引，并请求确认；随后开始后台索引，UI 立即可用。
- 新建 vault：选择位置与名称，创建 `daily/`、`.aero/`、一篇"欢迎"笔记（介绍 Live Preview、`/`、`[[`、`⌘P`、`⌘⇧P`）。
- 欢迎笔记与示例库都是普通 Markdown，可以改、可以删。
- 准备示例库失败（同名文件、符号链接、磁盘写不进去）时留在这一页并显示原因，不静默降级。

### 示例库

「查看示例库」把内嵌的中文示例交付到应用数据目录下的 `demo-vault/` 并打开，停在欢迎页。示例覆盖使用方法、排版（含颜色、公式与 mermaid）、双链与别名、笔记嵌入、标题 / 块引用、项目组织和移动改名练习，彼此互链，并故意留一个未解析链接演示淡色虚线与"点击才创建"。源码在 `assets/demo-vault/`，编译期嵌入可执行文件，所以每个安装包带的都是该次构建的示例。

示例库是用户的笔记而不是缓存，交付因此是增量的：`.aero/demo.toml` 记下每篇最近一次交付的内容指纹，再次进入时只替换指纹仍然吻合（即用户没动过）的示例，补上这一版新增的示例；用户改过的保持原样，删掉或改名的不恢复。没有这份交付记录的同名目录（用户自己建的 `demo-vault/`）一个字都不写。首次交付先在临时目录里准备完整副本再整体改名发布，半成品不会成为用户的库。

示例库跟着应用数据目录走：重装应用通常保留，连同应用数据一起删除才重新初始化。它会进入最近列表；从最近列表点进去、或启动时自动恢复到它，都走上面的更新流程并停在欢迎页（不是最近改过的那篇），这样新版示例和更新说明总能被看到。

## 13. 设计系统

### 13.1 字体

- 界面：系统字体（SF Pro → PingFang SC 回退）。
- 正文：默认系统字体，16 px，行高 1.7（中文），字重 400；可换为用户安装的任意字体。
- 代码：SF Mono → JetBrains Mono → Menlo，14 px，CJK 回退到 PingFang SC。
- 标题：H1 1.75×、H2 1.4×、H3 1.2× 正文字号，字重 600；H4–H6 与正文同号、字重 600。
- 中文标点使用全宽，中西文之间不自动加空格（保持源码原样）。

### 13.2 间距与尺寸

- 基础单位 4 px。块间距：段落 8 px，标题上方 24 px / 下方 8 px，列表项 4 px，代码块/富内容上下 12 px。
- 正文列宽 720 px；行内最大字符数约 40 个汉字，符合阅读舒适区。
- 侧栏行高 28 px；面板内边距 12 px；圆角 6 px（弹层 10 px）。

### 13.3 颜色令牌

```text
bg.app          窗口底色
bg.surface      面板 / 弹层
bg.editor       编辑区
bg.hover        悬停
bg.selected     选中块 / 选中行
border          分隔线
text.primary    正文
text.secondary  次要信息、淡化的 Markdown 标记
text.disabled
accent          链接、焦点环、主要按钮
danger / warning / success / info
callout.{note,tip,warning,danger,info,question,example,quote}
content.text.{gray,brown,orange,yellow,green,blue,purple,pink,red}   用户上色的文字（7.7）
content.bg.{gray,brown,orange,yellow,green,blue,purple,pink,red}     用户上色的背景；bg.yellow 同时是 == 高亮色
code.*          语法高亮（复用 Zed 主题的作用域命名）
```

浅色与深色各一套，默认跟随系统。深色下正文不使用纯白（`#E6E6E6`），底色不使用纯黑。`content.*` 在两种主题下都要满足文字对比度 AA：文字色深色主题下提亮，背景色深色主题下降低饱和度而不是简单反相。

### 13.4 图标与动效

- 图标：Lucide（gpui-component 默认资源），16 px 描边。
- 动效：只用于状态过渡——弹层 120 ms 淡入、块落位 300 ms 高亮、横幅 150 ms 滑入。没有装饰性动画；系统"减弱动态效果"开启时全部关闭。

### 13.5 专注模式与打印样式

专注模式下正文列宽保持 720 px，背景与编辑区同色，光标所在段落不做高亮（避免打字机效果的干扰）。导出 PDF/打印使用同一套排版令牌（M4）。

- **M1b**：标签页条、快速打开、命令面板、全文搜索视图、文档内查找、索引进度、代码块工具条、toast 系统。
- **M2**：`[[` / `#` / `![[` 补全、链接悬停预览、未解析链接创建、反链面板、标签视图、文件树拖放与重命名同步、图片粘贴/拖放与查看、嵌入块、数学渲染、`.assets/` 折叠显示、`⌘⇧E`、选区浮动工具条、文字/块颜色（在 M1 阶段 `⌘⇧H` 只做 `==` 高亮）。
- **M3**：变更面板与 MCP 状态项、搜索的语义开关与模型下载、mermaid 与 PDF 块、数学/mermaid 源码态实时预览、隐私设置页。
- **M4**：链接卡片、属性结构化编辑、标签重命名、未链接提及、分栏、局部图谱、HTML 粘贴转换、字符级跨块选区、导出/打印。标记隐藏与按需源码提前，见 `project_plan.md` 9.1。

## 17. 待验证的交互假设

这些判断需要在 M1a 自己用起来之后再确认，可能推翻：

1. ~~聚焦块切换到源码态时"保持标题字号、淡化标记"是否足以避免视觉跳动。~~ 已定并落地：默认隐藏标记，源码按块或按篇打开（`project_plan.md` 9.1）。
2. 跨块选区升级为块级选区（而非字符级）在实际写作中是否够用，尤其是"选中一段半的文字复制"这种场景。
3. `Esc` 两段式退出（编辑 → 块选中 → 浏览）会不会被误触；备选是 `Esc` 只到块选中态。
4. 悬停 500 ms 出链接预览会不会太频繁；备选是默认"按住 ⌘"。
5. `.assets/` 默认隐藏 + 📎 徽标是否足够发现附件。
6. 属性条以只读 chips + 源码编辑起步，用户是否接受到 M4 才有结构化编辑。
7. 状态栏同时放五项信息是否过载；候选是把字数移到文档 `⋯` 菜单。
8. 颜色写成 `[文本]{.red}` / `段落 {.bg-blue}` 后，在 GitHub 等不识别属性列表的地方留下的字面噪音是否可接受；如果自己都受不了，备选是只保留块颜色（噪音只在块末一处）而砍掉行内颜色。
9. 浮动工具条在鼠标松手时立刻出现会不会挡住下一步点击；备选是延迟 200 ms 或只在鼠标静止后出现。
